

# Interactive Rating Component

This is a simple and responsive interactive rating component built with HTML, CSS, and JavaScript. The user can select a rating from 1 to 5, submit it, and view a thank-you message with their selected score.

![Design Preview](./design/desktop-preview.jpg)

## 🚀 Project Overview

- The user selects a rating from 1 to 5.
- On submission, the selected rating is displayed in a confirmation screen.
- Includes input validation to ensure a rating is selected before submission.

## 🧪 Features

- Clean, minimal UI
- Active state styling for rating buttons
- Error handling if no rating is selected
- Responsive layout for both desktop and mobile devices

## 🛠️ Built With

- HTML5
- CSS3 (with optional SCSS)
- Vanilla JavaScript
